# Afore-Coppel

## Análisis académico AFORE · CRISP-DM

Base sintética longitudinal 2015–agosto de 2026. Incluye análisis descriptivo, churn, ingresos futuros por comisiones, segmentación K-means/K-medoids, tablas dinámicas y un tablero interactivo.

- [Descargar entrega completa ZIP](https://github.com/a01769651/Afore-Coppel/raw/refs/heads/main/analisis/Analisis_AFORE_Completo.zip)
- [Ver notebook ejecutado](analisis/entrega_afore/Analisis_AFORE_CRISP_DM.ipynb)
- [Instrucciones para ejecutar](analisis/entrega_afore/LEEME.md)
- [Hallazgos y niveles de confianza](analisis/entrega_afore/HALLAZGOS.md)
- [Descargar tablero HTML](https://github.com/a01769651/Afore-Coppel/raw/refs/heads/main/analisis/entrega_afore/tablero_interactivo.html): guardar y abrir en el navegador.

No se inventan costos, presupuesto ni efectividad de campañas. El ingreso bruto futuro no equivale a CLTV neto. Se incluyen IC95% de métricas e intervalos predictivos nominales al 90%, con cobertura temporal observada. Las probabilidades del modelo de churn requieren recalibración antes de usarse para decisiones económicas.
